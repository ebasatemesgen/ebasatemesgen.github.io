# Unused Files

This folder contains files moved out of active site paths to keep the project organized.

- `pages/`: old draft pages not linked by the main site
- `images/`: old or replaced images
- `images/root-legacy/`: former top-level `images/` files with random names not referenced by active pages
- `images/fulls-legacy/`: unreferenced files moved out of `images/fulls/`
- `videos/`: old or replaced video assets
- `scripts/`: old or broken script files replaced by newer versions
- `scripts/3d-moon/`: retired Three.js moon experiment files
- `docs/`: optional area for unlinked documents

Files here are intentionally not used by current pages.
